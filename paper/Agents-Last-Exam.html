Evaluate agents on completed professional workflows

02Method

Task specifications turn generated artifacts into verifiable scores

  • Agents use graphical tools and shell commands in a virtual machine.
  • Task-specific checks compare generated artifacts with hidden references or explicit rubrics.

04Interpretation

Verifiable task completion is a step toward reliable professional AI

  • Scores measure completion of professional computer tasks, not improvements in patient outcomes.
  • Deterministic checks are preferred; some visual tasks require structured LLM judgments.
  • The private task pool and rolling releases are designed to reduce benchmark contamination.
  • Failure analysis identifies missing domain knowledge and unsuitable strategies as major challenges.
The failure analysis uses model-assisted review of Claude Code + Opus 4.7 runs. Section 3.3, Section 2.3 and Appendix D.3.
