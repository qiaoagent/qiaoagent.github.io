# bio/

Master copies of Qiao Jin's bios. `homepage.md` is rendered by index.html at load; edit it and the page changes. Each `.md` has a plain-text `.txt` twin with the links removed, and `index.html` lists them all at qiaojin.info/bio/; both are made by `python3 bio/build.py`, so run it after every edit or new file (add a one-line description to `DESC` in build.py for a new bio). Add other variants (a talk bio, a one-liner) as new `.md` files here.
